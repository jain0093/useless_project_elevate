## Basic Details
### Team Name: Elevate


### Team Members

- Member 2: Diya B - JAIN University, Kochi

### Project Description
AVASTHA is an unnecessarily advanced camera-powered website that watches what people are currently doing and turns their visible activities into fictional NPC encounters, pointless quests, brutally specific roasts, meme reactions, and Malayalam meme audio.

It uses computer vision to detect people, movement, posture, objects, and group situations — all for absolutely no useful reason.

### The Problem (that doesn't exist)
People are constantly doing suspiciously ordinary things — sitting around, staring at laptops, scrolling on phones, walking nowhere, and pretending to be productive.

Nobody is judging these situations with sufficient technological sophistication.

### The Solution (that nobody asked for)
AVASTHA uses computer vision to observe the current scene, randomly selects a visible person, figures out what they are actually doing, and gives them an unnecessarily detailed NPC identity, a useless quest, a painfully accurate roast, a meme reaction, and a Malayalam meme audio clip.

Because apparently computer vision needed a worse purpose.

### Workflow / Architecture

```text
User
  ↓
Webcam / Device Camera
  ↓
Live Video Feed
  ↓
TensorFlow.js + COCO-SSD
  ↓
Person Detection
  ↓
Select Random Current-Frame Person
  ↓
MediaPipe / Visual Activity Analysis
  ↓
Observable Activity
  ↓
Gemini API
  ↓
NPC Type + Quest + AI Opinion
  ↓
Meme Image + Malayalam Meme Audio
  ↓
NPC Encounter Screen
  ↓
Next Victim / Stop Scanning
```
Camera → Computer Vision → Person & Activity Detection → NPC Generation → Roast & Quest → Meme Image + Malayalam Audio → AVASTHA Encounter
