# 🎭 AVASTHA — MEME ASSETS DIRECTORY

This directory houses the categorized Malayalam reaction meme assets according to the AVASTHA Master Architecture.

## Category Folders:
- `/public/memes/sitting/` — Memes for sitting/unproductive/motionless individuals (e.g., Salim Kumar in chair, Mohanlal motionless, Harisree Ashokan).
- `/public/memes/standing/` — Memes for standing around doing nothing/loitering (e.g., Jagathy standing confused, Innocent staring into void).
- `/public/memes/walking/` — Memes for pacing/aimless walking (e.g., Mukesh walking with purpose to nowhere).
- `/public/memes/phone/` — Memes for phone addiction/scrolling (e.g., Jagadish staring at screen, Salim Kumar screen glare).
- `/public/memes/laptop/` — Memes for pretending to work on laptop/deadline panic.
- `/public/memes/group/` — Memes for group project chaos/crowds around one screen.
- `/public/memes/idle/` — General 0% productivity/blank mind memes.
- `/public/memes/confused/` — Confusion/loading screen memes.
- `/public/memes/unclear/` — Occluded or unclear activity memes.
- `/public/memes/no-victim/` — Empty lobby / ghost memes.

## File Format:
Place `.webp`, `.png`, or `.jpg` reaction images in these folders.
The application includes high-fidelity SVG/emoji and typography fallbacks whenever local audio/image files are pending or absent.
